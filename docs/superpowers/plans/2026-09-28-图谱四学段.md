## 关键实现点

### 1. 四份源文件、一个解析器

沿用初中那份的写法（`##` 册 / `###` 章 / `####` 节 / `-` 末级），只加三样：

```
## 七年级（上）
> 来源: https://…        ← 册下面一行来源（生成时打进数据，缺了就报错）

### 第一章 有理数 [数与代数]     ← 章行尾方括号里是课标领域
#### 1.1 知识速查
- 正数和负数
```

- 章号支持三种：`第一章`（初中 / 高中）、`第一单元`（小学）、无编号（竞赛）。
- 学段由"哪个文件"决定，不由内容猜。

### 2. 学段合成根

```js
function stageScope(code) { … }   // 复用 fieldScope 的手法：depth 0，kids = 该学段的册
```

册在数据里的 depth 是 1，所以合成根放 depth 0（与 `MATH_TREE` 根同层），列位置不用特判。

### 3. 分法随学段变

```
小学   : 教材册次 / 四大领域（数与代数·图形与几何·统计与概率·综合与实践）
初中   : 年级教材 / 几何代数（数与代数·图形与几何·统计与概率）
高中   : 教材册次 / 课标主题（预备知识·函数·几何与代数·概率与统计·数学建模活动与数学探究活动）
竞赛   : 四大板块（分法栏收起）
```

分法栏的两格**标签**与**选项**都由学段配置生成，不是写死在 HTML 里的。

### 4. 章号挂册短名

`八下 18`。册的短名：小学「三上」、初中「八上」、高中「选必二」、竞赛没有章号（板块下的章不编号）。

## 执行记录

### 数据与生成器

- `tools/build-math-tree.rb` 重写成「一份配置 + 一个解析器」：`STAGES` 四段（小学 / 初中 / 高中 / 竞赛），
  共用一套 `##` 册 / `> 来源` / `> 待核` / `### 章 [领域]` / `#### 节` / `-` 末级 的写法。
- 章行三种写法共用一个正则：`第一章`（初中 / 高中）、`第一单元`（小学）、`不编号`（竞赛）。
  正则多捕一个「章 / 单元」，数据里多一栏 `unit`，阅读器标题才不会把小学的「第 3 单元」写成「第 3 章」。
- 来源与领域是硬约束：缺来源直接停下；领域没写、写错、或竞赛带了领域，都停下。
  来源缺失这一条在源文件里补了 6 处（初中六册）。
- 生成结果：**27 册 / 板块 · 169 章 · 520 节 / 栏目 · 574 末级条目 · 90.6 KB**
  （小学 12/88/273、初中 6/29/170、高中 5/22/77、竞赛 4/30/0）。

### 图谱

- 学段按钮放在工具条**最前面**（用户点的顺序就是先选学段再看别的一格）。
- 学段是册上的一栏（`stage`），不是新加的一层；选学段用「学段合成根」（depth 0）复用「领域合成根」那套手法。
- 分法随学段变：教材册次 / 四大领域（小学）、年级教材 / 几何代数（初中）、教材册次 / 课标主题（高中）、
  四大板块（竞赛，第二栏整条收起）。分法栏的字样与选项都由学段配置生成。
- 竞赛的册是「板块」（`kind: track`），量词跟着变（`stageBooksWord()`），章号挂册短名（`必修一 01`）。
- 名单里对待核的册挂「待核」标记；节点面板显示待核原因与目录来源。

### 阅读器

- 左栏手写的六册 29 章删掉，改由 `reader-live.js` 按当前学段现建 —— 不这么做，
  手写的那棵树必然和数据脱节（而且章号跨册会撞：小学每册都从「第一单元」重来，
  高中必修 / 选必各自排，竞赛不编号）。
- 章在学段内的键：**只有章号在本学段里唯一时才用章号**，否则用「册序号 c 章序号」，
  否则点第八册的第一个单元会翻到别的册去（这条有断言守着）。
- 学段键与图谱共用 `wkmath.graph.stage`；在图上选了高中，过来阅读器也是高中。
- 正文如实写出「这一处还没核到」与「目录来源」，不假装齐了。
- 折叠逻辑仍在 `pages.js`，但它被挂到 `MathSite.initReaderTree` 上 —— 重建之后要能补绑一次。

### 顺带修的两处

- 39 个页面的页脚范围声明原来写死「人教版七至九年级 · 六册二十九章」，已改成「小学到高中四套教材 · 竞赛章节框架」。
- `run_all.rb` 原来只把断言与语法算进退出码，Ruby 体检的红灯只是打印出来。
  这一次差点因此漏过一次（`reader.html` 被误删了正文与右栏，断言全绿、退出码 0，
  只有 `verify_bridges` 在喊）。现在体检红灯单独统计、单独报，也影响退出码。

### 验收

  - `fieldScope` 不按学段缓存 → 8 条红（初中的「图形与几何」底下混进 33 章）。
  - 体检红灯门槛 → 把 `.lg--stage{` 改坏，`run_all` 退出码 1 并单列 `verify_graph.rb 1 条`。
