# 白板「分析 / 答案」实施计划

> **给执行的 agent：** 配套子技能 `executing-plans`（逐任务执行 + 检查点复核）。本仓库没有 `subagent-driven-development`。步骤用 `- [ ]` 勾选跟踪。
>
> **读代码时先认这几个已有的东西**，不要另造一套：`whiteboard.js` 里已有 `byId(id)`（就是 `document.getElementById` 的别名）、`press(el, on)`（切激活态）、`state.view`、`problemLayout()`、`persist()` / `restore()`、`wrap`（画布容器）。测试桩里已有 `document.createElement`、`getBoundingClientRect`、`localStorage`、`classList`，但要本次补 `removeChild`；桩里**没有** `setTimeout`。
>
> **上游文档（先读）：**
> - `docs/superpowers/specs/2026-09-28-白板题目底纹与AI分步分析-design.md`（设计，本计划覆盖 §2 #2～#7、§3.2、§5、§7 的一部分）
> - `docs/1.0-版本日志.md` §4 规范（**红线必须先读**，尤其新增的 §4.8「画布规范」）、§5 流程

**Goal:** 在题面旁放两个很轻的按钮 —— 「分析」浮出 1～5 个可写可拖的台阶框（**只给该往哪儿看，不给答案**），「答案」在题目下方标出结果并可用一个开关在「显示注释 / 干净答案」之间切换。

**Architecture:** 题面本身仍然是 canvas 上按世界坐标绘制的底纹（Plan 1 已交付，不动它）。**分析 / 答案这一层是 DOM 浮层**，作为 `.wb-canvas-wrap` 的绝对定位子元素、与 `<canvas>` 互为兄弟 —— 位置由世界坐标投影出来（`left = view.x + wx * scale`），所以跟着板走（平移 / 缩放都会重排），但**字号不跟着缩**（台阶要能读、能写，缩到 15% 就没法用了）。数据来自新建的 `assets/js/whiteboard-analysis.js`，本版是预置内容（设计 §5），换真服务只换这一个文件。

**Tech Stack:** 原生 HTML / CSS / JavaScript（零构建）、Canvas 2D、osascript 断言桩、Ruby 体检脚本。

---

## 交付边界

**本计划做：** 题面旁的「分析 / 答案」按钮、步骤框（浮出 / 拖动 / 可写 / 落盘）、答案块与注释开关。

**本计划不做**（各自单独出计划）：
- 上传图片、「我的题」标签、只存文字的存储 → Plan 3
- 真 AI 识别与分步分析（本版全是预置数据）
- 图谱掌握层标记（A）、图谱结构搬到白板（B）

**为什么先做这一份而不是上传：** 上传那条链路的终点就是「识别出的题面 + 分析 + 答案」，先把分析/答案这条界面链路做通，上传接进来时只要换数据源（设计 §5「只换识别 + 分析这一个调用点」）。

### 三个必须先知道的约束（踩了会红）

1. **新样式要放在第二个 `<style>` 块里，不能放进 `<style id="wb-styles">`。** 那个块是图谱共享样式的**母版** —— `tools/build_graph_css.rb` 会把它整段读出、把 `wb-` 改名为 `mm-` 后写进 `graph.html`。放进去，图谱就会多出一堆用不到的台阶框 / 答案块规则。
2. **`data-wb-tip` 的总数被体检钉死在 14**（`verify_whiteboard.rb`）。新按钮不要挂 `data-wb-tip`；它们自己有「分析 / 答案」两个字，本来也不需要气泡。
3. **`border-radius:999px` 的总数被体检钉死在 6**（同上）。新样式一律不用 999px：圆形用 `50%`，胶囊用具体圆角。

```js
/* ==========================================================================
   数字白板 —— 「分析 / 答案」的预置数据
   --------------------------------------------------------------------------
   本版**不接真 AI**（设计 §5）：分步引导语、标准答案、注释全是预置的。
   接入真服务时，只需要把下面的 steps() / answer() 换成一次网络调用，
   界面层（whiteboard.js）完全不动 —— 所以这份数据不会因为换模型而返工。

   两条硬规矩（设计 §2 #3 / #6）：
   1. 「分析」只给"该往哪儿看"，**不许出现答案** —— 给了答案，前面几级台阶就没人走了。
   2. 「答案」分干净与带注释两态：注释解释"为什么这么想、哪里易错"。
   ========================================================================== */
window.WK_ANALYSIS = (function () {
  'use strict';

  /* 通用台阶：与具体题目无关，所以**任何题都有得推**。
     刻意一个数字都不写 —— 一写数字就变成答案了。 */
  var SCAFFOLD = [
    '先只看题目在问什么：要求的到底是哪一个量？把它写进下面的框里。',
    '把题目给出的条件逐条抄下来，一条一行，先不管怎么算。',
    '想一想：这些条件和要求的东西之间，隔着哪一步运算？把那一步写下来。',
    '按你写的那一步算一遍，中间结果留在框里。先别急着对答案。'
  ];

  /* 预置答案：只给演示题库里几道最简单的题，其余走 NO_ANSWER。
     result 是"这道题的答案长什么样"，断言用它守住"分析里不许出现答案"这条规矩。 */
  var PRESET = {
    '7a-01': {
      result: '−4',
      lines: [
        { text: '−7 + 3 = −4', note: '异号相加：先比绝对值。|−7| > |3|，所以结果取负号。' },
        { text: '', note: '再用大的绝对值减小的：7 − 3 = 4，连上负号就是 −4。' }
      ]
    },
    '7a-02': {
      result: '10',
      lines: [
        { text: '6 − (−4) = 6 + 4 = 10', note: '减去一个负数等于加上它的相反数。括号里的负号最容易漏。' },
        { text: '', note: '把减法统一成加法之后再算，符号就不会错。' }
      ]
    },
    '7a-03': {
      result: '10',
      lines: [
        { text: '(−2) × (−5) = 10', note: '同号相乘得正 —— 两个负号约掉了。' },
        { text: '', note: '再把绝对值相乘：2 × 5 = 10。' }
      ]
    },
    '7a-04': {
      result: '−3',
      lines: [
        { text: '(−18) ÷ 6 = −3', note: '异号相除得负。' },
        { text: '', note: '绝对值相除：18 ÷ 6 = 3，再补上负号。' }
      ]
    },
    '7a-13': {
      result: 'x = 2',
      lines: [
        { text: '3x + 5 = 11 → 3x = 6 → x = 2', note: '先把不含 x 的项移到一边：两边同时减 5。' },
        { text: '', note: '再把 x 的系数化 1：两边同时除以 3。' }
      ]
    }
  };

  /* 没预置答案时怎么说 —— 要老实，不要编 */
  var NO_ANSWER = '本版的分析与答案是预置演示数据，这道题还没预置标准答案。接入真服务后，这里会由 AI 给出。';

  /* 台阶：本版对所有题给同一套通用台阶。
     接真服务时这里接收题面文字（data.text），返回该题专属的 1~5 级台阶。 */
  function steps(data) {
    return SCAFFOLD.slice();
  }

  /* 答案：没有预置就返回 null，由界面层给出 NO_ANSWER 的说明 */
  function answer(problemId) {
    return PRESET[problemId] || null;
  }

  return {
    steps: steps,
    answer: answer,
    NO_ANSWER: NO_ANSWER,
    SCAFFOLD: SCAFFOLD,
    PRESET: PRESET
  };
})();
```

```js
   10. 分析与答案的预置数据
   ============================================================ */
var AN = window.WK_ANALYSIS;
assert(!!AN, '数据模块已挂到 window.WK_ANALYSIS');
assert(typeof AN.steps === 'function' && typeof AN.answer === 'function',
  '数据模块给出 steps() 与 answer() 两个入口');

var guides10 = AN.steps({ text: '−7 + 3' });
assert(guides10.length >= 1 && guides10.length <= 5,
  '台阶数量在 1~5 之间（实际 ' + guides10.length + '）');

var allText10 = guides10.join(' ');
var bad10 = [];
for (var i10 = 0; i10 < guides10.length; i10++) {
  if (!guides10[i10] || typeof guides10[i10] !== 'string' || !guides10[i10].trim()) bad10.push(i10);
}
assert(bad10.length === 0, '每条台阶都是非空文字（空的是 ' + JSON.stringify(bad10) + '）');

/* 「分析」不许出现答案 —— 设计 §2 #6 的核心规矩 */
var leaked10 = [];
for (var id10 in AN.PRESET) {
  if (!AN.PRESET.hasOwnProperty(id10)) continue;
  var res10 = AN.PRESET[id10].result;
  if (!res10) continue;
  if (allText10.indexOf(res10) >= 0) leaked10.push(id10 + ' 的答案 ' + res10);
}
assert(leaked10.length === 0,
  '通用台阶里不出现任何预置答案（漏的是 ' + JSON.stringify(leaked10) + '）');

assert(AN.answer('7a-01') && AN.answer('7a-01').result === '−4',
  '能取到 7a-01 的预置答案');
assert(AN.answer('不存在的题') === null, '没预置的题返回 null（由界面层给说明）');
assert(typeof AN.NO_ANSWER === 'string' && AN.NO_ANSWER.length > 10,
  '没预置答案时有一句老实的说明');
```

- [ ] **Step 6: 加投影与浮层定位**

在 `assets/js/whiteboard.js` 里 `function problemLayout()` 的**下方**插入：

```js
  /* ---------- 分析 / 答案：DOM 浮层 ---------- */

  /* 世界坐标 → 画布内坐标（CSS 像素）。
     这些浮层是 .wb-canvas-wrap 的绝对定位子元素，与 <canvas> 的 CSS 盒子共享同一个原点，
     所以**不加** getBoundingClientRect().left —— 加了反而会多偏一个左边距（这一处踩过）。 */
  function boardToScreen(wx, wy) {
    var v = state.view;
    return { x: v.x + wx * v.scale, y: v.y + wy * v.scale };
  }

  function toggleHidden(el, hide) {
    if (!el) return;
    el.hidden = !!hide;
    if (hide) { if (el.setAttribute) el.setAttribute('hidden', 'hidden'); }
    else if (el.removeAttribute) el.removeAttribute('hidden');
  }

  function setText(el, s) {

    var acts = byId('wb-acts');

      var ah = acts.offsetHeight || 26;

      acts.style.top = Math.min(Math.max(4, anchor.y), maxY) + 'px';
    }
  }
```

- [x] **Step 5: 加台阶框的逻辑**

在 `assets/js/whiteboard.js` 的 `function toggleAnswer()` **下方**插入：

```js
  /* ---------- 台阶框 ---------- */

  var MAX_STEPS = 5;

  /* 台阶的引导语：只给"该往哪儿看"。本版是预置数据，接真服务只换这一个调用点。 */
  function stepGuides() {
    var api = (typeof window !== 'undefined' && window.WK_ANALYSIS) ? window.WK_ANALYSIS : null;
    if (!api || typeof api.steps !== 'function') return [];
    var list = api.steps(cardData());
    return (list && list.length) ? list.slice(0, MAX_STEPS) : [];
  }
  function stepGuide(i) { return stepGuides()[i] || ''; }

  /* 台阶框的初始落位：题面右侧、依次向下错开。
     偏移量按屏幕像素折算成世界单位 —— 这样不管当前缩放多少，看起来都是同一套间距。 */
  function defaultStepAt(i) {
    var box = problemBox;
    var k = state.view.scale || 1;
    return {
      wx: box.x + box.w + (26 + i * 16) / k,
      wy: box.y + (i * 104) / k
    };
  }

  /* 展开台阶：位置只在第一次落位时算，之后跟着学生拖的结果走 */
  function openAnalysis() {
    var n = stepGuides().length;
    if (!n) return 0;
    for (var i = 0; i < n; i++) {
      var s = state.analysis.steps[i];
      if (!s) { s = { wx: null, wy: null, text: '' }; state.analysis.steps[i] = s; }
      if (s.wx === null || s.wy === null) {
        var d = defaultStepAt(i);
        s.wx = d.wx; s.wy = d.wy;
      }
    }
    state.analysis.steps.length = n;
    state.analysis.open = true;
    state.analysis.answerOpen = false;   /* 点「分析」先把答案收起来（设计 §2 #6） */
    redraw();
    persist();
    return n;
  }

  function closeAnalysis() {
    state.analysis.open = false;         /* 收起不是清空：学生写的内容留着 */
    redraw();
    persist();
  }

  function analysisOpen() { return !!state.analysis.open; }

  function setStepText(i, text) {
    var s = state.analysis.steps[i];
    if (!s) return null;
    s.text = String(text == null ? '' : text);
    var pad = byId('wb-step-pad-' + i);
    /* 只有真的不一样才回写 DOM —— 否则每敲一个字都会把光标顶到末尾 */
    if (pad && pad.textContent !== s.text) pad.textContent = s.text;
    /* 这里**故意不 persist()**：本函数挂在 input 事件上，每敲一个字都会调用一次，
       而 persist() 会把最多 800 笔笔迹整体 JSON 序列化一遍 —— 每敲一个字写几百 KB 会卡。
       落盘交给失焦（blur）和拖动结束（onStepUp）。 */
    return s.text;
  }
  function stepText(i) {
    var s = state.analysis.steps[i];
    return s ? (s.text || '') : '';
  }
  function stepPos(i) {
    var s = state.analysis.steps[i];
    return s ? { wx: s.wx, wy: s.wy } : null;
  }

  function renderSteps(ctx) {
    var guides = stepGuides();
    for (var i = 0; i < MAX_STEPS; i++) {
      var box = byId('wb-step-' + i);
      if (!box) continue;
      var on = ctx.has && state.analysis.open && i < guides.length;
      toggleHidden(box, !on);
      if (!on) continue;
      setText(byId('wb-step-guide-' + i), guides[i]);
      var s = state.analysis.steps[i];
      var pad = byId('wb-step-pad-' + i);
      if (pad && pad.textContent !== (s ? (s.text || '') : '')) pad.textContent = s ? (s.text || '') : '';
      if (box.style && box.style.setProperty) box.style.setProperty('--i', String(i));
    }
  }

  /* 拖台阶框：手柄是标题栏。手上拖的是屏幕像素，世界位移除以 scale —— 和拖题面同一条规矩。 */
  var stepDrag = null;

  function onStepDown(idx, e) {
    var s = state.analysis.steps[idx];
    if (!s || s.wx === null) return;
    var head = byId('wb-step-head-' + idx);
    stepDrag = { idx: idx, id: e.pointerId, sx: e.clientX, sy: e.clientY, wx: s.wx, wy: s.wy };
    var box = byId('wb-step-' + idx);
    if (box && box.classList) box.classList.add('is-dragging');
    if (head && typeof head.setPointerCapture === 'function') {
      try { head.setPointerCapture(e.pointerId); } catch (err) { /* 忽略 */ }
    }
    if (typeof e.preventDefault === 'function') e.preventDefault();
  }

  function onStepMove(idx, e) {
    if (!stepDrag || stepDrag.idx !== idx || e.pointerId !== stepDrag.id) return;
    var s = state.analysis.steps[idx];
    if (!s) return;
    var k = state.view.scale || 1;
    s.wx = stepDrag.wx + (e.clientX - stepDrag.sx) / k;
    s.wy = stepDrag.wy + (e.clientY - stepDrag.sy) / k;
    layoutOverlays();
    if (typeof e.preventDefault === 'function') e.preventDefault();
  }

  function onStepUp(idx, e) {
    if (!stepDrag || stepDrag.idx !== idx) return;
    if (e && e.pointerId !== undefined && e.pointerId !== stepDrag.id) return;
    var box = byId('wb-step-' + idx);
    if (box && box.classList) box.classList.remove('is-dragging');
    stepDrag = null;
    persist();
  }

  /* 每个台阶框各挂各的 —— 把序号闭包进来，
     比在事件里 closest('.wb-step') 反查更稳（桩里 closest 永远是 null）。 */
  function initStepDrag() {
    for (var i = 0; i < MAX_STEPS; i++) {
      (function (idx) {
        var head = byId('wb-step-head-' + idx);
        if (!head || !head.addEventListener) return;
        head.addEventListener('pointerdown', function (e) { onStepDown(idx, e); });
        head.addEventListener('pointermove', function (e) { onStepMove(idx, e); });
        head.addEventListener('pointerup', function (e) { onStepUp(idx, e); });
        head.addEventListener('pointercancel', function (e) { onStepUp(idx, e); });
        var pad = byId('wb-step-pad-' + idx);
        if (pad && pad.addEventListener) {
          pad.addEventListener('input', function () { setStepText(idx, pad.textContent); });
          /* 失焦时落盘：打字过程不写，离开这个框才写一次 */
          pad.addEventListener('blur', function () { persist(); });
        }
      })(i);
    }
  }
```
