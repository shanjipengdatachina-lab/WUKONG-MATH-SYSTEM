## 关键实现点

### 1. 桩里必须有一个可控定时器

轮播的坑几乎都在"时间"上：定时器没清、悬停没暂停、手动翻页后不重新计时。
所以 `bn-harness-head.js` 里自带 `setInterval / clearInterval`：

```js
var __clock = { seq: 0, timers: [], cleared: 0 };
function tick() { __clock.timers.slice().forEach(function (t) { t.fn(); }); }
function liveTimers() { return __clock.timers.length; }
function liveIntervalMs() { return __clock.timers.length ? __clock.timers[0].ms : 0; }
```

这样"间隔就是 8000""悬停时没有活着的定时器""destroy 之后 0 个"都能直接断言。

### 2. 组件对外接口

`WK_CAROUSEL = { INTERVAL, SWIPE_MIN, activeBanners, nextOf, prevOf, mount, boot, instance }`。
`mount()` 返回 `{ root, shell, track, slides, dots, prevBtn, nextBtn, playBtn, count, interval, still,
index, goTo, next, prev, play, pause, playing, timerActive, destroy }`。

### 3. 为什么幻灯片用 createElement 逐张搭

`innerHTML` 一次铺完更短，但那样 `<img>`、圆点、按钮都不是真元素 —— 图片加载失败的分支、
`aria-current` 的切换、定时器的清理都断言不到。**能测的边界比短三行重要。**

### 4. 箭头用内联 SVG

这一层是脚本建出来的，`lucide.createIcons()` 早就跑过去了，挂 `<i data-lucide>` 不会被替换成图标。
