## 关键实现点

### 1. 合成根：只要 depth 对，其它全不用特判

```js
function fieldScope(name) {
  var kids = [];                       // 按册序、章序收集
  DATA.kids.forEach(function (book) {
    (book.kids || []).forEach(function (ch) { if (ch.field === name) kids.push(ch); });
  });
  var node = { id: 'f:' + name, name: name, kind: 'field', depth: 1, parent: null,
               kids: kids, hasChildren: true, agg: <孩子 agg 求和>,
               kidsSet: <孩子 id 索引> };
}
```

与"册"同层（depth 1）→ 列位置、字号、盒子、档位全都不用改。

### 2. locate() 的关键一行

```js
if (scopeKey) {
  var scope = rootScope();
  if (!scopeContains(scope, node) && node !== DATA) setBookFilter('');
}
```

`scopeContains` 除了沿父链，还要看 `scope.kidsSet` —— 章的真实父节点是册，永远走不到合成根上。

### 3. 分法跟着范围走

```js
function axisOfScope(key) {            // 参数可传一个范围进去
  var k = (key === undefined) ? scopeKey : (key || '');
  if (!k) return '';
  if (isFieldScope(k)) return 'field';
  return BOOK_SHORT[k] ? 'book' : '';
}
function initialAxis() {               // 启动那一栏 = "刷新一次会落在哪一栏"
  var derived = axisOfScope(initialScope());
  ...
}
```

`initialAxis()` 刻意从 `initialScope()` 现算：启动时 `scopeKey` 还没赋值，
只看现场变量会算错（这条第一版写错、被断言抓出来了）。

### 2026-09-28 · 完成

生成器加领域表、29 章全部带上课标领域、图谱加分法与两栏、体系当根、体检修掉一处会静默失效的守线。
断言 816 → **868** 条，0 失败。

**两处执行时才发现的：**

1. **`initialAxis()` 第一版算错了**。它只看现场的 `scopeKey`，而"模拟刷新"时 `scopeKey` 还是旧值 ——
   断言 `范围是册时，分法落在年级教材那一栏（期望 book，实际 field）` 当场抓出来。改成从
   `initialScope()` 现算（等价于"刷新一次会落在哪一栏"），`axisOfScope()` 加了一个可选参数。
2. **体检里 `shared` 变量用在了定义之前**（我的新守线在第 65 行，`shared` 原在第 191 行）——
   Ruby 会直接 NameError。把它提到文件开头，与其它读取放一起。
   同一轮还发现本机 Ruby 是 **2.6.10**（系统自带），**没有 `Hash#tally`**，改成手数一遍。

**证明过它能红（两次，各自隔离）：**

- 让 `fieldScope()` 不过滤领域（`ch.field === name || true`）：**9 条 FAIL**，数字都有意义 ——
  `图形与几何底下 13 章（期望 13，实际 29）`、`可见 = 体系 + 13 章（期望 14，实际 30）`、
  `说明里写清…共 13 章（实际"共 29 章"）`、`别体系的章算"在范围外"（期望 false，实际 true）` 等。
- 把 `kidsSet` 置空：**正好 2 条 FAIL** ——
  `同体系的章算"在范围内"（期望 true，实际 false）`、`在范围内定位 → 筛选不动（期望 图形与几何，实际 空）`。
  这两条就是"合成根最容易漏的地方"，单独证明它咬得住。
- 生成器漏登记的出口也验过：临时删掉 `'圆' => '图形与几何'` 一行，脚本报
  `第 912 行：「圆」没有登记课标领域。` 并以退出码 1 停下。
