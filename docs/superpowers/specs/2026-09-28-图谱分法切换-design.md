## 1. 背景与用户原话

> 「这里上面加个 tab，默认按『年级教材』分，还可以按照『几何代数』分；点击几何代数；就会出两个体系」

摸数据时发现一处和原话对不上：**源数据里 29 章没有任何几何 / 代数的分类字段**，而且按课标打是
**三个**领域（数与代数 13 章、图形与几何 13 章、统计与概率 3 章），不是两个。统计与概率那 3 章
（数据的收集整理与描述、数据的分析、概率初步）在"只分两栏"里无处可去。

三个判断点问过用户，回答：

1. **三个体系都列**（不硬凑两个）
2. 点了某个体系 → **把该体系当根**（和"选一册"同一套机制）
3. 章的节点上**不带册名**（保持干净）

## 2. 决定

| # | 决定 | 理由 |
| --- | --- | --- |
| 1 | 领域字段进**生成器**（`build-math-tree.rb` 的 `FIELDS` 表），写进每个章节点 | 数据带在数据里；白板 / 练习页将来也能用；`ruby tools/build-math-tree.rb` 一跑就重新对账 |
| 2 | 新加一章却没登记领域 → **生成器直接报错退出** | 漏一章不会崩、只会安静地少一块，最难发现 |
| 3 | 判定按课标；`平面直角坐标系` 归**图形与几何** | 课标把"图形与坐标"放在几何里。这是唯一容易被觉得"应该算代数"的一章，在代码里写明了 |
| 4 | 浮层顶部一条两格切换：**年级教材**（默认）/ **几何代数** | 用户明确要求 |
| 5 | 切分法**只换名单，不动图** | 与"点开浮层只是看看"一致；图要等你点具体某一项才变 |
| 6 | 点一个体系 → 该体系**当根**（合成节点，`kind:'field'`，`depth:1`） | 和"选一册"共用一套机制：布局、折叠、档位全不用改 |
| 7 | 章的**真实父节点仍是册**，信息面板的路径照实显示 | 体系是"看法"不是真层级，不编造层级 |
| 8 | 合成节点自带**孩子索引 `kidsSet`** | `locate()` 判断"目标在不在当前范围里"是沿父链往上走，走不到合成根上 —— 没有这张表，在几何范围内定位"平行四边形"会被误判成"在别处"并把筛选清掉 |
| 9 | 分法**跟着范围走**：范围是体系就亮几何代数那一栏 | 否则出现"我选的东西在看不见的那一栏里" |
| 10 | 分法本身也落盘（`wkmath.graph.axis`） | 上次看哪栏，下次还看哪栏（范围是总览时才有意义，范围能说明一切） |
| 11 | 名单与工具条上用**课标全称**，工具条上显示**短名**（几何 / 代数 / 统计与概率） | 与"册"一致：名单里写「七年级（上）」，工具条写「七上」 |
| 12 | 类型徽标写「体系」；图例补一行「体系」 | 它不是"册"，写成册就是错的 |
| 13 | 顺手把 `#mm-book-menu` 从 `role="menu"` 改成 `role="group"` | 菜单里必须放 menuitem 并实现方向键语义，这里两样都没有；再加嵌套的分法条，写成菜单就更假了 |
| 14 | 修掉体检里一处**会静默失效**的守线 | `book_menu` 原来用 `<div…>.*?</div>` 抓，遇到嵌套就停在第一个 `</div>`，"不许出现假快捷键徽标"那条会从"扫全盘"变成"只扫开头" |

## 3. 数据形状

章节点新增一个字段：

```js
{ name: "平行四边形", kind: "chapter", no: "18", field: "图形与几何", cn: "十八", children: [...] }
```

## 4. 界面

```
#mm-book-menu[role=group]
├─ #mm-axis[role=group]            ← 年级教材 / 几何代数（两格，aria-pressed + is-on）
├─ [data-axis-pane="book"]         ← 原 7 项（总览 · 六册 + 六册）
└─ [data-axis-pane="field"][hidden] ← 4 项（总览 · 全部体系 / 图形与几何 / 数与代数 / 统计与概率）
```

工具条第一个按钮上的字：总览 / 七上 / **几何**；提示气泡：「只看某一册或某一体系 · 当前 …」。
说明浮层的图例补一行「体系」，正文补一句"同一张网有两种看法"。

## 5. 验收

| 层面 | 守什么 |
| --- | --- |
| 数据 | 每章都有领域；领域恰好三个；13 + 13 + 3 = 29（不重不漏）；生成器漏登记就退出 |
| 默认 | 默认停在年级教材那一栏，册那一栏露出、体系那一栏收起 |
| 切分法 | 点几何代数 → 名单换、图**不动**（节点数不变）；分法落盘 |
| 体系当根 | 根的 kind 是 `field`、底下 13 章、都是真章、没有别的体系的章混进来；可见数 = 1 + 13；章名不带册名 |
| 短名 | 工具条显示「几何」；说明文字写清"共 13 章（课标名：图形与几何）" |
| 刷新 | 范围是体系时，刷新回来仍在体系那一栏；范围是册时在册那一栏；认不出的范围当没存 |
| 定位 | 同体系的章不清筛选；别体系的章才清（`kidsSet` 的作用） |
| 体检 | 分法条两格齐、两栏各有一个"总览"、体系项恰好 4 个且三个课标领域都在、图例有体系行、样式不在共享区、浮层不是 `role=menu`；**并验证浮层捕获能扫到最后一项** |

## 6. 刻意不做的

- 不改成两个体系（统计与概率无处可去，硬凑就是撒谎）。
- 不在体系视图里给章节点补册名（用户选的"保持干净"）。
- 不新建页面、不改导航；分法是同一张图上的两种看法。
- 不做"领域"的第二层（如几何下再分三角形 / 四边形 / 圆）。
