## 1. 背景

论坛首页现在从上到下是：视图切换条（最新 / 热门 / 我的帖子）→ 发帖框（收起）→ 三个专题卡 →
最新主题列表，右侧是「活跃作者 / 本周热议」侧栏。用户要求在上方加一个**轮播图模块**，
带圆角、默认 8 秒滚动一张，并且以后后台能添加图片和对应的活动、公告内容。

这个站的三条现状决定了设计：
1. **一张图都没有**（没有 `assets/img` 目录）；
2. **没有后台**，纯静态零构建、双击可离线打开，一贯做法是"本机数据 + 可替换的读取函数"；
3. **没有公告 / 活动详情页**，而自检有一条断链体检 —— 链接不能先挂空。

## 2. 决定

| # | 决定 | 理由 |
| --- | --- | --- |
| 1 | **通栏**横跨两列（`grid-column:1 / -1`），在视图切换条之下、两列内容之上 | 视觉上真正的"首页最上方"，改一行 CSS，不动现有两列布局 |
| 2 | 内容与组件**分两个文件**：`forum-banners.js`（只有数据）/ `banner-carousel.js`（通用组件） | 以后后台只改"从哪读数据"；组件不认识"论坛" |
| 3 | 组件在加载末尾**自己挂载**（页面上有 `#forum-banner` 就搭起来） | 页面不用写初始化；加载顺序反了会挂到空列表上，这条用体检守 |
| 4 | 默认 **8 秒**一张（`INTERVAL = 8000`） | 用户明确要求 |
| 5 | 图片**不带字**，标题 / 副标题 / 按钮用 HTML 叠在图上 | 文字永远清晰、可改、能读屏；换图不用重做标题 |
| 6 | 图上盖一层遮罩（左深右浅的 scrim） | 白字压在任何底图上都够对比度，不靠"图应该不太亮"这种侥幸 |
| 7 | 每条链到**已存在的页面**（`exams.html` / `graph.html` / `whiteboard.html`），配一个"去看看"按钮 | 站内没有公告详情页；断链体检只扫 HTML，扫不到 JS 里的链接，所以另加守线逐个检查能不能落地 |
| 8 | 文案只写**站上真有的事**，不编"限时折扣""月底截止" | 不编造。要促销文案由用户提供 |
| 9 | 控件：圆点 + 左右箭头 + **暂停 / 继续**按钮 | 自动轮播属于"会自动更新的内容"，无障碍规范要求有能停下来的机制；光靠悬停暂停对键盘用户等于没有 |
| 10 | 悬停**或焦点**进来都暂停 | 只在悬停时暂停，键盘用户享受不到 |
| 11 | `prefers-reduced-motion: reduce` → 完全不自动播，且不放暂停按钮 | 减少动效下没有东西会自动播，摆一个按下去什么都不会发生的按钮更糟 |
| 12 | 0 张 → 整块 `hidden`；1 张 → 不轮播、不画圆点与箭头 | 不留空白条；不摆"点了没反应"的东西 |
| 13 | 非当前那张 `aria-hidden` + 链接 `tabindex=-1` | 否则 Tab 会跑到看不见的图上 |
| 14 | 自动播时 `aria-live="off"`，手动翻过之后转 `polite` | 自动播时一直播报是打断读屏；人手动翻时才需要念 |
| 15 | 上线下线（`from` / `until`）做成**纯函数** `activeBanners()`，但三条内容都不填 | "公告到期下线"是公告的固有语义，接后台当天就要用；但内容里不填，避免哪天悄悄消失 |
| 16 | 轮播不记进度 | 记"上次看到第几张"对公告没意义，刷新回第一张最符合预期 |
| 17 | 手指左右滑切换，阈值 40px | 自实现，不引库；小抖动不算翻页 |
| 18 | 图片给死宽高、非首张懒加载、加载失败退回渐变色底（`is-broken`） | 不产生布局跳动；不留裂图标 |

## 3. 数据形状

```js
window.WK_BANNERS = [
  { id, kind: '活动'|'公告', title, sub, image, alt, href, cta, from?, until? }
];
```

- `image` 建议 1280×400（3.2:1）；`alt` 必填（底图不带字，这是读屏唯一的信息）。
- `href` 必须是站内真实页面。
- `from` / `until` 可选，不填即常驻。

## 4. 界面结构

```
#forum-banner（通栏，默认 hidden，由脚本展开）
└─ .bn[role=region][aria-roledescription=轮播][aria-live]
   ├─ .bn-track（transform: translateX(-k*100%)）→ .bn-slide × n
   │    ├─ img.bn-img  ├─ span.bn-scrim  └─ span.bn-copy（类型标 / 标题 / 副标题 / 按钮）
   ├─ .bn-arrow--prev / .bn-arrow--next（悬停或焦点进来才显形）
   ├─ .bn-dots（.bn-dot[aria-current]）
   └─ .bn-play（暂停 / 继续）
```

高度：`aspect-ratio:3.2/1`，`min-height:150px`、`max-height:320px`；窄屏（≤640px）改 2:1 并隐藏副标题。

## 5. 图片为什么是 SVG 而不是 AI 出图

原计划生成三张无字的 AI 底图，但**本机没有配置出图密钥**（`ARK_API_KEY` / `MODEL_IMAGE_API_KEY` /
`MODEL_AGENT_API_KEY` 全为空），所以改为手绘三张 SVG 底图：

- 仍是**真实图片文件**，模块与"以后换照片"的路径没有区别（只改 `image` 一个字段）；
- 每张约 2KB，比照片轻两个数量级（仓库总共 1.75MB）；
- 无字，且明度落在可控区间里，遮罩的对比度才有保证；
- 三张分别对应三个真实功能：答题卡（真题卷）、节点网（知识图谱）、手写曲线加圈（白板演算台）。

拿到密钥后想换成照片，改三行 `image` 即可，其它一律不动。

## 6. 验收

| 层面 | 守什么 |
| --- | --- |
| 内容 | 3 条、字段齐、`image` 与 `href` 都能落到真实文件（**断链体检扫不到 JS，这条自己守**） |
| 上线下线 | 纯函数：在窗口内 / 常驻 / 坏日期当没填 留下；未开始与已结束滤掉 |
| 自动播 | 间隔就是 8000；拨一次表翻一张；转一圈回到第一张；手动翻到边界绕回 |
| 暂停 | 悬停停、移开继续；焦点进停、离开继续；暂停按钮文案与 `aria-pressed` 同步；手动翻页是"重新计时"而不是"永久停播" |
| 减少动效 | 不建定时器、轨道带 `is-still`、不放暂停按钮、手动仍可用 |
| 边界 | 1 张不画圆点与箭头、不自动播；0 张整块收起 |
| 滑动 | 超过 40px 才翻页；小抖动不翻 |
| 读屏 | 非当前张 `aria-hidden` + `tabindex=-1`；自动播时 `aria-live=off`、手动后 `polite` |
| 不泄漏 | `destroy()` 后没有活着的定时器；重建也只留一个 |
| 图片 | 首张不懒加载、其余懒加载；有死宽高；失败加 `is-broken` 并清空 `alt` |
| 真机 | 圆角可见、通栏、8 秒真的翻页（连续观察三次含绕回）、白字压图上清晰可读 |

## 7. 刻意不做的

- 不做"轮播记住上次看到第几张"。
- 不做多条同时可见（一次只露一张）。
- 不接真后台；不做出图（没有密钥）。
- 不给轮播绑快捷键。
- 不做视频 / 动图轮播。
