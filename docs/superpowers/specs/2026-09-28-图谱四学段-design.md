## 1. 背景与用户原话

> 「增加一下：加上小学 一到六年级；高中：高一到高三；按照人教版来添加；竞赛模块：可以先添加到章节的
> 框架类数据；避免后期再返工设计；对应的图谱设计需要增加和改进一下；可以在图谱按钮最前面，
> 选择是小学 初中 高中 还是竞赛；是不是好点；」

回答用户那个问题：**是**，而且不只是"好点"，是必须的 —— 一屏放不下四个学段的册，
所以"总览"的含义必须从"全部册"改成"当前学段的册"。

## 2. 已核对的事实（都是查过来源的，不是凭记忆）

| 学段 | 册数 | 结构 | 来源层级 |
| --- | --- | --- | --- |
| 小学 | 12 册（一上～六下） | 单元（章）→ 小节 | 人教社 2024 换版：**一、二、三年级新版**（6~7 单元/册）、**四、五、六年级旧版**（8~10 单元/册） |
| 初中 | 6 册 | 章 → 节 | 本站已有的《人教版初中数学知识结构.md》 |
| 高中 | 5 册（必修一/二 + 选必一/二/三） | 章 → 节（18 章 / 73 节） | 人教社官方培训页 + 官方教科书 PDF（必修）+ 权威电子课本目录（选必） |
| 竞赛 | 四板块 | 板块 → 章（30 章） | **板块**有权威依据（联赛加试四个范围）；**章名是归并的**（2006 大纲条目 + 《数学奥林匹克小丛书》分册名） |

**三处必须如实标出来的不确定：**

1. 小学**二年级下册、三年级下册**的 2024 新版目录**没核到**（电子课本站还在放旧版）——
   这两册先只放册节点，章节留空，并标「待核」。
2. 小学新版个别单元的小节只到单元、没有课时细分 —— 那些章标「小节待核」。
3. 竞赛的**章**不是任何单一权威的原文，是我们的编排 —— 数据文件里写明来源层级，
   不装作它是官方目录。

## 3. 决定

| # | 决定 | 理由 |
| --- | --- | --- |
| 1 | **学段是"册"上的一个字段，不是树上的一层** | 加一层就变 6 层，折叠档位、面板统计、阅读器、默认深度全要往后挪一格，而收益为零（学段是大分区，不会在同一屏里既展开学段又展开册）。与上次给章加"领域"是同一手法 |
| 2 | 选中某学段时用**合成根**把它当整张图的根 | 复用「几何代数」那套机制，一处代码两处用 |
| 3 | **领域标注写在源 .md 里**（章行尾的 `[数与代数]`），不再放生成器的硬编码表 | 章名跨学段会撞（小学和初中都有「圆」），按名字查表必然出错；写在行上则一一对应、一眼可核对。初中那份也一并迁过去，四份用同一套机制 |
| 4 | 四份源文件、一个解析器 | 教材结构继续是**人类可读、可 diff、可让用户直接改**的文件，而不是埋在代码里的哈希 |
| 5 | 每册标注**来源 URL**，缺一个生成器就报错退出 | 这份数据会直接给学生看；来源必须能被追问 |
| 6 | 「**总览**」= 当前学段的全部册 + 章 | 一屏放不下四学段；而且看总览时心里想的就是某一个学段 |
| 7 | 工具条**最前面**加「学段」按钮（小学 / 初中 / 高中 / 竞赛） | 用户指定；它是最大的分区维度，决定下面能选什么 |
| 8 | **分法那一栏跟着学段变** | 小学 = 教材册次 / 四大领域；初中 = 年级教材 / 几何代数；高中 = 教材册次 / 课标主题；竞赛 = 只有板块（那一栏收起）。四套课标领域的名字各不相同，全站共用一套必然说错 |
| 9 | 竞赛的册位置放**四大板块**，类型徽标写「板块」 | 它们确实不是教材 |
| 10 | 章号挂上**册的短名**（`八下 18`） | 上次就发现体系视图里 `04 / 05 / 07 / 11` 看不懂；跨学段后更看不懂 |
| 11 | 待核的册 / 章带 `pending` 标记，信息面板里如实显示 | 空的册会被当成"忘了填"；有依据的空缺和没做是两件事 |
| 12 | 阅读器（章节索引）**只列当前学段，默认初中** | 与图谱读同一份数据；不这么做，那边会一口气列出 21 本册 |
| 13 | 本期做到「册 + 章 + 节」，知识点下一期 | 用户选的"先做到书"；结构一次做对，内容分批填 |

## 4. 数据模型

```
MATH_TREE
└─ root（初中数学知识结构 → 现在是"数学知识网络"）
   ├─ 册 / 板块   kind:'book' | 'track'，带 stage:'primary'|'junior'|'senior'|'olympiad'
   │   └─ 章      kind:'chapter'，带 field:'<课标领域>'（可选 pending）
   │        └─ 节 kind:'section'（竞赛没有这一层）
   └─ …
```

册上新增：`stage`（必填）、`source`（来源 URL，必填）、`pending`（可选，说明为什么空）。

## 5. 界面

- 工具条最前：`#mm-stage-btn`（显示当前学段）+ 浮层四项。
- 「总览」= 当前学段的册；学段切换**重新落一次视图**（不然会停在上一学段的坐标上，看着像空板）。
- 分法栏：标签与选项都跟着学段走；竞赛学段把整条分法栏收起。
- 章号：`<册短名> <章号>`（学段内所有视图统一）。
- 信息面板：有 `pending` 的节点多一行灰字说明。
- 阅读器：侧栏一行学段切换（与图谱共用同一个记忆键）。

## 6. 验收

| 层面 | 守什么 |
| --- | --- |
| 数据完整性 | 每册都有 stage 与 source；每章都有 field；每章的 field 在该学段允许的领域集合里；竞赛不得出现"节"层 |
| 数据一致性 | 各学段的册数 / 章数 / 节数与核对后的目录一致（写成断言里的期望值，改动就会被发现） |
| 待核 | 待核的册必须是"有 pending 且无子节点"；不许悄悄留空 |
| 学段切换 | 切学段 → 只列该学段的册；总览 = 当前学段；切完视图重新落位（不残留上一学段的坐标） |
| 分法 | 分法栏随学段变；竞赛不出现分法栏；各学段的两套分法项齐 |
| 重名 | 跨学段重名（小学「圆」vs 初中「圆」）不许让定位 / 关联串台 |
| 阅读器 | 只列当前学段；默认初中；与图谱共享学段记忆 |
| 体检 | 四份源文件都在且都能解析；生成物里 stage/source 齐；图谱与阅读器都挂了学段控件 |
| 真机 | 四学段各切一遍，册数章数与抽查清单对得上；一屏不出现别的学段 |

## 7. 刻意不做的

- 本期不填知识点（末级条目）——下一期。
- 不按"高一上/高一下"分册（人教A版是按册的，按年级会写成一句各地不一样的话）。
- 不给竞赛做难度分级（没有权威依据）。
- 不给小学做"新版/旧版"两套并存的切换（按"当前在用"取一套；等换版再换）。
- 不在学段之上再加"全部学段总览"（一屏放不下，也没人这么看）。
