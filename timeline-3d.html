X 轴 = 知识序列（一年级 → 六年级）· Y 轴 = 综合难度（1–5 档）· Z 轴 = 学习时间（底部那条时间条）
**右侧那排**是难度层的五个档：基础层（绿）· 概念层（蓝）· 应用层（黄）· 变化层（橙）· 综合层（红）—— 点名字就开 / 关那一层
**拖动底部时间条**：柱子那堵墙在时间里滑、颜色按那一天算，滑过哪一场的日子，那一块考试切片才冒出来
一块玻璃板 = **一次考试**：点住它 → 板上考点用曲线连到对应的柱子、底部排出一串考点点（**颜色 = 难度档、红圈 = 做错**），其余柱子灰显；旋转焦点也跟着搬到这一场
拖动 = 转视角（**不限角度**）· Shift 拖动 / 右键拖动 = 平移 · 滚轮 = 放大缩小 · 平面那一档拖动就是平移
