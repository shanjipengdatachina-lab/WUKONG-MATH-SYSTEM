X 轴 = 知识序列（左端是早学的、右端是晚学的，**轴上不写字**）· Y 轴 = 综合难度（1–5 档）· Z 轴 = 学习时间（底部那条时间条）
**右侧那一竖排**是**唯一不会被收走**的一排（「清爽模式」收左边与底下，不收它）：**回到总轴**（松开钉住的那一场 / 点开的考点 / 点中的题，视角铺满整根轴 —— 角度与三根轴的拉伸都留着；钉着某场时提示是「回到总轴」，已经在总轴上时是「已经在总轴」）· **难度层**（点开在**边上**弹出那五档：基础层（绿）· 概念层（蓝）· 应用层（黄）· 变化层（橙）· 综合层（红）—— 勾哪几档就画哪几层）· **考试分析**（先在图上点住一块玻璃板，再点它 → 左边弹出那一块；再点一下收起）· **清爽模式**（把左侧导航与底部工具条 / 时间条滑走，只看场景；再点一下恢复）
**底部时间条上那排小圆点** = 考试日历：一个点 = 一场考试，**压在时间条那条线上**、摆在它那一天的位置（**拖动时间条时会一场一场跟着冒出来**，跟场景里那些玻璃板同一把尺子）；两个点挨得太近（还有同一天考两场的）会把其中一个往上挪一点点。**点一下那个点就选中那一场**，当前钉住的那场点是金色的；**鼠标划过去，场景里对应那块切片会亮一下**
**拖动底部时间条**：柱子那堵墙在时间里滑、颜色按那一天算，滑过哪一场的日子，那一块考试切片才冒出来
一块玻璃板 = **一次考试**：板上按难度切出 1–5 五条刻度；**划到板上某个考点**时光标是小圆圈、那个点被圈住并写出「编号 · 名字」（红色 = 这场做错了）。**点住这块板** → 只做两件事：相机**聚焦到这一场**（缩放收敛、角度转到**俯视**；再点一下松开 —— **松开只是把钉子放开，视角原样留着**）、其余柱子灰显 —— **不弹任何浮窗**（在**总轴上**时板里的那些考点点是**不参与点击**的 —— 那么小，优先让你点到整块板；这一场钉住之后，板上的点才是主角。要看分析去右侧点「考试分析」）。**进了单个考试之后，只有右侧那颗「回到总轴」能把视角送回整根轴** —— 画布上点什么都不会把你踢出去；同时板上考点用曲线连到对应柱子，柱墙底**往场景里面**排出一排**题**（一个点 = 卷面上的一道题，整排长度 = 这块切片宽度的 3.3 倍；每个点从它在轴上的柱脚扯一条引线过来，**题号只标做错的那几道**、用虚线牵出去）。**点某一道题**（点那个点，或者点它那行「第 N 题」的字都行）→ 弹出**这个考点**的面板（面板里列着这一场考到的那几道题，点中的那道在里面也标着），画布上**只亮这一道**；**点板上的考点点 / 柱顶** → 才是"点知识点"，它那 2~3 道题一起亮。**点空白** = **取消选择**（选中的那个点 · 点开的考点 · 点中的那道题 · 钉住的这一场，一起放开；两个浮窗收起 —— **镜头不动**，你自己调好的角度和缩放都留着；要回整根轴，点右边那颗「回到总轴」）。钉住某一场时，**时间轴那根棱**上"这场考试那天"的位置会画一小道刻度 + 一个实心点，并从切片底边拉一条虚线指过去（**不再在轴上写年月日** —— 那行字跟底部时间条自己的日期挤在一起太糊；要哪一天看时间条那行）
左边那块浮窗是**两个页签**：**分析**（这一场考了哪些考点，每行写着**这一场考到第几题** · 正确率 · 小结）/ **试卷**（复刻这张卷子的每一道题：第几题 · 考点 · 难度 · 满分 / 得分 · 对错，存数据不存照片）—— 贴左上角、抓标题栏可以拖走、正文整块滚。**点其中某一道题** → 图上那道题和它对应的知识点**一起高亮**；**点某个考点** → 从这根**柱子斜着**拉几根虚线，连到这一场里它考到的那几道**题**，那些题点一起亮、并套上圈
底部那三颗是数据图层（各开各关）：**学习进度** 和 **成绩变化** 是**并排的两块图板**（横轴都是时间；左边那块纵轴 = 累计完成的格数，实线 = 实际 / 虚线 = 计划；右边那块纵轴 = 每场得分率，点一下那个点就钉住那一场）· **投入练习**（每两周的新题 / 复做题量，还在地面左端那串柱上）
**三根轴可以各自缩放**：把光标移到**某一根轴**上（那根轴会亮起来、字变"缩放"），滚轮就**只拉长 / 压短这一根** —— 时间轴拉长了，6 年就不会挤成一团；X 轴（知识）、Y 轴（难度）同理。光标**底下的那一格**会钉住不动、两边展开。拉歪了点底部工具条上那颗**「适配」**（就在 − / ＋ 旁边）：没选中东西 = 整根轴回画面；钉住某一场 = 适配这一场；点开着某个考点 = 适配这个考点那一段
**划到东西**：鼠标底下那一个点会套一个**白圈**，同时"学习时间"那条时间条的**上方**浮出一行字 —— 是**哪一道题**（`第 18 题 · 考的是「…」· 8 / 10 · 错`），或者哪个**考点**、哪一场**考试**。**点这一行** = 打开这个考点的面板，把那道题一起高亮
拖动 = 转视角（**不限角度**）· Shift 拖动 / 右键拖动 = 平移 · 滚轮 = 放大缩小（压在轴上 = 只缩那一根轴）· 平面那一档拖动就是平移
