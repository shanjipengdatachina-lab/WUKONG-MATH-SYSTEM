产品规划 · 数字白板

数字白板：从「能写」到「解题闭环」

这不是一个通用白板。它的定位是数学演算台：题目、知识点、方法、易错点、公式都能一键送上板， 用户在板上演算，过程留在题上，不用重抄一个字。

二、顶级白板在做什么

三家代表产品的能力侧重不同，取它们的长处即可，不必样样都做。

产品值得学的能力对本站的启发
Goodnotes 手写数学公式即时验算（Math Assist）；手写方程可转成排版公式与 LaTeX；手写转可编辑文本、可被 AI 检索与总结；AI 数学助手分「讲给我听」与「直接解」两种模式 来源：goodnotes.com/ai、Math Assist 说明 「写完能被读懂」是数学白板的核心价值：手写算式识别 + 即时校验 + 分步提示，是 P3 的主线
Miro 无限画布；画笔画的草图能自动转成形状、便签与连线；上千套模板；协作与外部工具集成 来源：miro.com/whiteboard 无限画布 + 墨迹转形状（直线、圆、辅助线）是画几何图的关键，属于 P2
Excalidraw 极简速记、随手打开就能写；链接即协作；离线可用、端到端加密；本地优先 来源：Excalidraw 与 Miro 对比、2026 白板横评 不要把白板做成功能堆砌的控制台：默认只有笔和橡皮，其余收在侧栏；打开即可写

三、规划（P1 → P4）

P1 · 把「上板」做成闭环 下一步

目标内容验收标准
一题一板 白板支持多页；从题目上板时自动开新页并带上题目与来源；页签可切换、可命名 连续从 3 道题上板，得到 3 页互不干扰的白板，切页笔迹不串
选择与编辑 套索选择：圈住后可整体移动、缩放、删除、改色；双击进入局部区域 圈选一段演算 → 拖到旁边 → 原位置留白，撤销后完全复原
导出与回看 导出 PNG（含题面）与 PDF；把当前白板挂回对应题目，在错题本 / 章节页可回看 导出图片含题面与笔迹；从错题条目的「白板」按钮进入能看到上次的演算

P2 · 画布能力对齐主流

目标内容验收标准
无限画布 平移 / 缩放（双指、滚轮、快捷键），视图与笔迹分离，缩放后笔迹不虚 缩放 25%–400%，笔迹边缘始终清晰；平移不影响已写内容
图形与直尺 直线 / 箭头 / 矩形 / 圆；长按出直尺画水平线；墨迹自动吸附成规整图形 手画一条歪线，松手后自动变直；画数轴不用再手抖
笔的细节 笔迹倾角、防误触（手掌抑制）、笔尾当橡皮、橡皮分「整笔擦」与「区域擦」两档 手掌贴屏书写不产生笔迹；翻转笔尾立即变橡皮
图层与纸张 底层 / 笔迹 / 标注三层；网格、点阵、方格三种纸；背景色（白板 / 深色 / 黑板绿） 切换纸张不丢内容；标注层可单独清空

P3 · 让手写被读懂（数学专属）

目标内容验收标准
算式识别 套住手写算式 → 转成排版公式（可复制为 LaTeX），并即时算出结果做校验 手写 (−2)×(−5) 识别为同一式并给出结果
分步提示 「讲给我听」模式：按本站方法速学的口径给下一步提示；「直接解」模式：给完整过程 提示口径与站点方法库一致，不出现教材外的解法
批改留痕 对自己写的解答逐步校验，标出第一处出错的位置 标错位置与站点易错速析的条目能对上

P4 · 协作与同步

  • 分享链接即协作（对齐 Excalidraw 的「粘贴链接就能一起写」）
  • 多人实时光标、老师点名上板、学生白板墙
  • 账号体系打通后白板跨设备同步；离线优先，联网后合并

四、本站的差异化

内容先于工具

通用白板要用户自己抄题。这里题目、知识点、方法、易错点、公式都在系统里，一个按钮就到板上——这是通用白板做不到的事。

演算与错题闭环

错题 → 上板演算 → 回看复盘。白板不是孤立页面，而是错题本、章节页、练习页的延伸。

克制

默认只有笔、橡皮、撤销；颜色和粗细在右侧栏，画布四周不留控件。宁可少一个功能，也不要让用户先学工具再用工具。

五、约束与取舍

  • 不引入重型依赖：站点是零构建的纯静态页，白板用原生 Canvas 2D + Pointer Events 实现，保持双击即可打开。
  • 离线优先：笔迹存本地，不依赖网络；识别与讲解这类重能力放在 P3，且要能在弱网下降级。
  • 不重复造轮子：手写识别、OCR 这类成熟能力优先接现成方案，只在「题目上板」「与知识图谱关联」这些差异点上自研。
  • 性能红线：单页 800 笔以内保持 60fps；超过后改为分块重绘。
