小学铺垫 · 同一知识点的前身

在直线上表示数

小学你已经在直线上表示过数了：把 0 定在中间，向右依次是 1、2、3……；把一个单位长度平均分成 10 份，就能表示 0.1、0.2……；平均分成若干份，就能表示分数。

那时候还没有学负数，所以这条直线只往右画——严格说，它还不是数轴。

小学示例

在直线上表示 0.6 与 3/4。

做法0.6 是把 0 到 1 之间的单位长度平均分成 10 份，从 0 向右数 6 份；3/4 是把同样的单位长度平均分成 4 份，从 0 向右数 3 份。

依据同一个单位长度，等分的份数不同，就能表示不同的数。

初中要在这条直线上做三件事

  • 把它补完整：向左延伸，才能放下负数；
  • 把规则写死：明确规定原点、正方向、单位长度；
  • 把用法升级：用「位置」来比较大小、表示距离。

01 · 讲解

为什么需要数轴

学会了正数和负数，能用它们表示相反意义的量了。但数还是一堆孤立的符号：−3 和 2 谁大？−2 和 2 谁离 0 更远？光看符号看不出来。

数是抽象的，位置是直接的。数轴做的事，就是给每个数安排一个位置。安排完之后，「比大小」变成「看左右」，「比远近」变成「数格子」。

定义

规定了 原点、正方向、单位长度 的直线叫做数轴。

三要素，缺一不可

  • 原点 作为「0」的基准点——定了它，才知道「从哪开始」。
  • 正方向 通常规定向右为正——定了它，才知道「往哪走」。
  • 单位长度 定了它，才知道「一格是多远」。

画数轴的四个步骤

  1. 画一条直线，两端不封口；
  2. 在直线上取一点作原点，标上 0；
  3. 规定正方向（一般向右），在直线右端画出箭头；
  4. 取适当的长度作单位长度，从原点向右每隔一个单位长度取一点，依次标 1、2、3……；向左同理标 −1、−2、−3……

结论

  • 表示正数的点在原点右边，表示负数的点在原点左边，0 就是原点本身；
  • 数轴上两个点表示的数，右边的总比左边的大——这是数轴最有用的一句话；
  • 任何一个有理数，都可以用数轴上的一个点来表示。

03 · 例题

三道题，看出数轴怎么用

例 1 · 判断三要素

下列各图中，是数轴的是（　）

  • A. 一条直线，有原点、有单位长度，但没有标明正方向
  • B. 一条直线，有原点、有正方向，但相邻刻度之间的距离不相等
  • C. 一条直线，规定了原点、正方向和单位长度
  • D. 一条射线，从 0 起向右延伸，刻度均匀

解析A 缺正方向，B 的单位长度不统一，D 是射线不是直线（无法表示负数）——三要素或「直线」这一条不满足，都不是数轴。选 C。

依据数轴的定义：规定原点、正方向、单位长度的直线。四个条件缺一不可。

例 2 · 画图与描点

画出数轴，并在数轴上表示 −3、−1.5、0、2、3.5。

步骤① 画一条直线，两端不封口；② 取一点作原点，标上 0；③ 规定向右为正方向，在右端画箭头；④ 取适当长度作单位长度，向右依次标 1、2、3……，向左依次标 −1、−2、−3……

描点在数轴上找到各数对应的位置描点，并把数写在点的上方。注意 −1.5 在 −2 与 −1 的正中间，3.5 在 3 与 4 的正中间。

依据数轴上的点与有理数的对应关系：每个有理数都能在数轴上找到唯一的位置。

例 3 · 数形结合（用到后续知识）

已知 a、b 在数轴上的位置满足 −2 < a < −1、2 < b < 3，比较 a、−a、b、−b 的大小。

思路把 −a、−b 也放到同一条数轴上，然后按「右边的大」直接读出来。

解析由 2 < b < 3 得 −3 < −b < −2；由 −2 < a < −1 得 1 < −a < 2。于是从左到右依次是 −b、a、0、−a、b，所以 −b < a < −a < b。

依据相反数的意义（数轴上关于原点对称的两个点）+ 数轴上右边的数总比左边的大。本题用到了后续的「相反数」，先看思路即可。

05 · 易错点

四条最容易踩的坑

1把「有箭头的直线」当成数轴

错在哪只画了箭头，没标原点或没说明单位长度，就认定它是数轴。

为什么错数轴的定义是三要素缺一不可，「有箭头」只满足了正方向这一条。

正确做法判断类题目第一步先查三要素，逐条打钩再下结论。

2刻度间距不相等

错在哪手画数轴时凭手感点点，相邻刻度间距不等。

为什么错单位长度必须统一；间距不等，「位置」和「数」的对应就断了，后面读坐标全错。

正确做法先用直尺定好一个单位长度，再等距截取，不要随手点。

3把数轴画成线段或射线

错在哪只画一小段就停笔，或者只画一个方向。

为什么错数轴是直线，要能向两方无限延伸，这样才能表示任意大小的数。

正确做法两端都要「出头」，只在正方向那一端画箭头。

4认为「数轴上的点都表示有理数」

错在哪把「有理数都能在数轴上表示」反过来用，认为数轴上的点与有理数一一对应。

为什么错反过来不成立：数轴上还有表示无理数的点（例如边长为 1 的正方形，其对角线长 √2，可以在数轴上精确作出）。

正确做法现阶段只要求会「有理数 → 点」这一步；这个坑会在第六章 实数正式补上，届时「数轴上的点与实数一一对应」才成立。

适用条件本条依赖学段：初中七年级（上）只能说「有理数都能在数轴上表示」，不能说「数轴上的点都是有理数」。

06 · 适用条件

什么时候能用、什么时候不能

  • 必须是直线：两端不封口、可向两方无限延伸；线段、射线都不是数轴。
  • 单位长度必须统一：同一数轴上相邻两刻度间的长度处处相等。
  • 三要素缺一不可：原点、正方向、单位长度必须同时规定。
  • 正方向可以自定：规定向右为正只是习惯；换成向左为正，数轴依然成立，只是左右关系整体反转。
  • 「有理数 → 点」成立，「点 → 有理数」不成立：后者要到第六章实数才补全。

07 · 感悟

这一节真正在教什么

三要素是「约定」，不是「真理」

为什么非得有原点、正方向、单位长度？因为数本身没有位置，位置是人给它安上去的。原点回答「从哪开始」，正方向回答「往哪走」，单位长度回答「一格多远」。三个都定死，一个数才有唯一的位置。

反过来想：如果把正方向规定成向左，数轴照样成立，只是所有左右关系颠倒了。这一手「先约定、再推理」，是整个数学最基本的工作方式——你后面学坐标系、向量、函数图象，会反复用到。

它是「一节课」，更是「三年的工具」

数轴在教材里只占 1.2 里的一个小节，看起来不起眼。但它其实不是一节内容：绝对值是「到原点的距离」，不等式（组）的解集要画在数轴上，函数图象是两条数轴搭出来的，动点问题几乎全在数轴上跑。

数轴是初中数学「数形结合」的第一块砖。它真正教会你的不是怎么画一条线，而是：遇到抽象的数，先想办法把它放到看得见的位置上。

高中延伸 · 同一个知识点的下一副面孔

数轴变成了什么

到了高中，数轴不再单独考，但它换了个身份继续用——从「一条线」变成「一维坐标系」。

三件事

  • 距离公式：数轴上两点 A(a)、B(b) 的距离为 |a − b|。初中说的「数格子」，到这里写成了一个式子。
  • 含绝对值的不等式：|x − 1| < 2 的意思是「到 1 的距离小于 2」，在数轴上就是一段区间。
  • 区间与集合：解集用数轴表示、用区间书写，数轴成了集合的直观画板。

高中示例

解不等式 |x − 1| < 2，并在数轴上表示解集。

思路|x − 1| 就是数轴上点 x 到点 1 的距离。

解析由 |x − 1| < 2 得 −2 < x − 1 < 2，解得 −1 < x < 3，解集为 (−1, 3)。在数轴上表示为从 −1 到 3 之间的一段，两端空心（不含端点）。

依据绝对值的几何意义——这正是初中那条数轴的直接延伸。

回头看初中

  • 初中打的那个「坑」（习题 4「数轴上的点不都是有理数」），在实数章会补全；
  • 初中说的「右边的总比左边的大」，就是高中「数轴上点的顺序与实数大小一致」；
  • 初中「距离 = 数格子」，就是高中 |a − b|。
