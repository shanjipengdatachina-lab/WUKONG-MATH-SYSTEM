# 悟空数学 · WUKONG MATH SYSTEM

把初中三年数学知识做成一张**可缩放、可下钻的图谱**，外面套一个 **IDE 化的外壳**：左边是栏目，中间是内容，需要演算时随时拉起**白板**，卡住时随手进**论坛**。

- 版本：**1.6**（版本历史见日志 §1）
- 形态：零构建静态站点 · 44 个页面 · 原生 HTML / CSS / JavaScript
- 依赖：无。不需要 npm，不需要打包器，双击 HTML 就能打开
- 字体：**阿里巴巴普惠体 3.0**（永久免费商用）。四个字重按站点用到的字**子集化后随仓库一起走**（`assets/fonts/`，共约 980KB），**不引任何 CDN**
- 自检：1452 条断言 + 15 项静态体检 + 断链 0

## 快速开始

```bash
# 本地预览（只用系统自带 Ruby，无需装任何 gem）
ruby serve.rb          # → http://127.0.0.1:5173/
ruby serve.rb 8080     # 指定端口

# 全量自检：1452 条断言 + JS 语法 + 静态体检，退出码 0 即全绿
ruby tools/checks/run_all.rb

# 只跑某几组
ruby tools/checks/run_all.rb wb graph
```

也可以直接双击 `home.html` 打开，但用 HTTP 访问体验更完整（相对路径、localStorage、剪贴板 API 更稳定；
另外 **Chrome 在 `file://` 下会拦掉本地字体文件**，双击打开时字体会回退到系统字体 —— 想看普惠体就走 HTTP）。

## 目录结构

```
├── *.html                  44 个站点页面（扁平放置）
├── assets/css/             tokens.css 设计令牌 / base.css / shell.css 骨架 / ide.css 外壳
├── assets/fonts/           阿里巴巴普惠体 3.0 子集（四个字重，共约 980KB，本地引用、无 CDN）
├── assets/js/              全局脚本，按固定顺序加载
├── tools/                  一次性改造脚本与生成器（幂等）
├── tools/checks/           自检体系（断言包 + 静态体检 + run_all.rb）
├── docs/                   文档
├── serve.rb                零依赖本地静态服务器
└── 人教版初中数学知识结构.md/.xmind
```

## 核心能力

| 模块 | 说明 |
| --- | --- |
| 外壳 | 固定左栏（悬停展开、状态记忆、`⌘B` 开合），栏目 8 + 4 |
| 章节 | 三栏阅读器，章节树默认展开，中栏换页不刷新 |
| 图谱 | 满屏画布 + 底部工具条（与白板同源），册/层级筛选、搜索定位、悬浮节点面板、按年级默认 |
| 时间轴 | 一屏一根**完整的**可缩放数轴（六级刻度随缩放细分：学段 / 年级 / 册 / 章 / 节 / 知识点）+ 掌握度彩条层（默认不画；六套色彩方案可选 —— 松绿 / 靛蓝 / 紫罗兰 / 琥珀 / 青碧 / 无障碍，各走一个明度基调，套内七档色相分明、压亮压暗都看得清）+ 悬停报名字（竖线 + 亮点指示那一格）/ 点击弹知识点卡片（可拖、位置记住、卡片里打标记）+ 当前学习 vs 当前观察双节点（观察点只由"点"决定，拖视野不动它）+ 图例条（七档状态 + 两节点 + 四类特殊标记）+ 标记的加 / 改 / 撤（卡片里点一下贴上、再点一次取消，可同时挂几个；"前置未满足"归系统只读）+ 筛选四维（阶段 / 掌握度 / 难度 / 标记，只变淡不动轴）+ 时间段对比卡（**按学期**，一学年上下两个）+ 方阵卡 + 底部缩略条（放大才出现，点拖即定位）；鼠标分工：滚轮缩放 / 右键拖动平移 / 左键点击。**3D 轴的数据地基也已就位**（K12 日历 + 学习轨迹事件流「首学 / 复习 / 纠错 / 考试」+ 考试实体，演示数据跨 2020-09 → 2026-06） |
| 时间轴 3D | 同一根轴的**立体观察层**（只读），**只看当前学段**（小学 / 初中 / 高中 —— 他还没走到的学段不摆上来）。**画布与渲染内核整段搬自参照原型**（投影 `cameraDistance = 110`、取景对称包围盒 + 右侧留 310px、两个轴都不夹角度可整圈转、难度层五个水平面、考试切片、知识柱带基点、命中 22px），**数据与外壳是我们的**：X = 知识序列（与平面同一根轴）、Y = 综合难度（1–5 档 × 4）、Z = 学习时间（**底部时间条**：前一天 / 日期 / 滑杆 / 后一天，一天一格、刻度按学年）。**拖动时间条**：柱子那堵墙在时间里滑、柱子颜色按那一天算（掌握度取轨迹里那一刻的值），而且只画**已经考过**的切片。**点住某一场**：只做两件事 —— 相机聚焦到这一场 + 其余灰显，**默认干干净净、什么浮窗都不弹**（要看分析去右侧那排点「考试分析」）；划过则只把切片边框描重。工具条（照白板：**纯图标**，汉字 hover 时才出）：3D ⇄ 平面 · 透视 ⇄ 正交 · 柱 ⇄ 曲线 · 按状态 ⇄ 按年级着色 · 考试切片开关 · 缩小 / 百分比 / 放大 / **适配** · 重置 · 帮助。**默认就是 3D**（一进来就是立体视角，那颗按钮回来切平面）。**轴上不挂文字**（年级名、X 轴标签、以及「Y · 综合难度」「Z · 学习时间」都收起来了 —— 只剩轴和刻度，年级信息由考试切片自己的名字给）。**右侧是一竖排按钮**（照白板那排，纯图标 + hover 汉字）：**回到总轴**（`axis-3d`；松开钉住的那一场 / 点开的考点 / 点中的那道题，视野铺满整根轴 —— **角度与三根轴的拉伸都保留**，钉着某场时提示是「回到总轴」、已经在总轴上时是「已经在总轴」）· **难度层**（**点开才展开**那五档 —— 而且是**从这竖排左边弹出一层**，不把这竖排自己撑高；勾哪几档就画哪几层）· **考试分析**（先点住一块玻璃板，再点它 → 在**左边**弹出那块浮窗，再点一下收起）。五档 = 基础层（绿）· 概念层（蓝）· 应用层（黄）· 变化层（橙）· 综合层（红），地面上那一层用它自己的颜色。**点住一块玻璃板**：相机**动画过渡到这一场**（~360ms、easeOutCubic，中心 / 缩放 / 两个角度一起插值 —— 用户一动手或滚轮就把动画停住，不跟人抢镜头；视野中心挪到这块板、缩放按"这一场 + 底下那一排题"给且**收敛**（最多 2.6 倍），**角度转到俯视（约 40°）** —— 让人一眼看出这场考试长的什么样、也看得清空间关系）。**进了单个考试之后，只有右上那颗「回到总轴」能把视角送回整根轴**（用户 2026-10-01："进入单个考试面板，只有右侧的回到总轴可以回去，其他的排查一下"）：再点一下这块板只是**松开钉子、视角原样留着**（原来那一下会连角度带缩放扔回总轴，而板面下半截随手一点就中），「重置视角」也改成**重新聚焦这一场**、不再回总轴。**不弹任何浮窗**（板上的覆盖点很密，所以这一场还没钉住时，点在板上任何地方都算"点这块板"；钉住之后再点板上的那个点，才是点那个考点），同时板上考点用曲线连到对应柱子的顶、柱墙底**往场景里面**排出一排**题**（**不是知识点** —— 一个点 = 卷面上的一道题，同一个考点考两道就有两个点；整排长度 = 这块切片宽度的 3.3 倍，这样拉开得开、每道题都认得出来），每个点从它在轴上的**柱脚扯一条引线**过来（就是"从柱状图分到这道题"那一根），颜色 = 这道题考的考点的难度档、**做错的整条用薄弱色**；**这一排站在时间轴尾巴再往外两年（≈2028 那一格）** —— 地面网格跟着画出去、轴外那段线更淡，但**轴外那两年不画刻度、也不写年份**（那个位置自己知道就行，不挂读数）；**题号不压在那排点上**：每个点往外拉一根**虚线**、字写在虚线末端，而且**只标做错的那几道**（对的题一个字都不写；错题太挤时按"至少隔 5 个世界单位"挑着标）；每场考试切片顶上还有一行**标题**（划过 / 钉住才写）—— `2023年10月16日 · 三年级 · 学年考 · 454 / 650 分` 这样，**年月日** · 年级场次 · 实得 / 满分一眼看完（年份就是这场考试在数据里的真实日期，不用再去轴上对）；钉住某一场时，还会从这块切片的底边**拉一根虚线**牵到**时间轴那根棱**上"这场考试是哪一天"的位置，轴上画一小道刻度、把**年月日**写在轴的左边（右边留给年份读数；放大到那根棱被挤出画面时，日期会**贴到画面边上**继续显示）；**点某个考点**（板上的点 / 那一排里的某道题）→ 除了弹出那个考点的小浮窗，还从**这根柱子的柱顶斜着拉几根虚线**连到这一场里它考到的每一道**题**（一个考点考三道就三根，斜着从同一个点发散出去），那些题点一起亮、并套上圈。左侧那块浮窗是一块**两个页签**的面板（头部照白板那块面板：抓手 + 页签 + ✕，正文整块滚、哪一页都不会被挤没；**贴着画布左上角一点点（12px）、高度跟着画布收，不会露到画布外**）：**分析**页 = 这一场考了哪些考点（每一行还写着"这一场考到第几题"）· 得分率 / 正确率 / 平均难度 · 按卷面算出来的薄弱小结；**试卷**页 = 复刻这张卷子的每一道题（第几题 · 考点 · 难度 · 满分 / 得分 · 对错，**存数据不存照片**）；**点其中某一道题** → 图上那道题和它对应的知识点**一起高亮**，点某个考点 → 在轴上点出那一格。**划过玻璃板**：板上按难度切出 1–5 五条刻度线；鼠标滑到板上某个考点上时**光标变成小圆圈**，那个点被圈住、就地写出「编号 · 名字」。**底部还有三颗数据图层**（照参照里的三个模块，各自独立开关）：**学习进度** 与 **成绩变化** 是**并排挂在盒子前缘正下方的两块图板**（横轴都是时间、正对观众、不挡柱子与年级名）—— 左板纵轴 = 累计完成的格数（刻度与轴上的格号对齐：整步长 + 顶上一格 = 这一段的总格数，实线 = 实际 / 虚线 = 计划，两条之间的开口就是欠下的量），右板纵轴 = 每场得分率（点住板上的点就钉住那一场）；**投入练习** 还在地面左端那条带上（每两周的新题 / 复做题量沿时间排开）。拖动转视角、Shift 拖动平移、滚轮缩放（.55 ~ 24 倍；**压在某一根轴上就只缩那一根** —— 三根轴各自可拉长 / 压短，0.4 ~ 4
