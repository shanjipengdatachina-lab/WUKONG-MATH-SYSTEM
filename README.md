# 悟空数学 · WUKONG MATH SYSTEM

把初中三年数学知识做成一张**可缩放、可下钻的图谱**，外面套一个 **IDE 化的外壳**：左边是栏目，中间是内容，需要演算时随时拉起**白板**，卡住时随手进**论坛**。

- 版本：**1.5**（版本历史见日志 §1）
- 形态：零构建静态站点 · 43 个页面 · 原生 HTML / CSS / JavaScript
- 依赖：无。不需要 npm，不需要打包器，双击 HTML 就能打开
- 自检：1396 条断言 + 13 项静态体检 + 断链 0

## 快速开始

```bash
# 本地预览（只用系统自带 Ruby，无需装任何 gem）
ruby serve.rb          # → http://127.0.0.1:5173/
ruby serve.rb 8080     # 指定端口

# 全量自检：1396 条断言 + JS 语法 + 静态体检，退出码 0 即全绿
ruby tools/checks/run_all.rb

# 只跑某几组
ruby tools/checks/run_all.rb wb graph
```

也可以直接双击 `home.html` 打开，但用 HTTP 访问体验更完整（相对路径、localStorage、剪贴板 API 更稳定）。

## 目录结构

```
├── *.html                  43 个站点页面（扁平放置）
├── assets/css/             tokens.css 设计令牌 / base.css / shell.css 骨架 / ide.css 外壳
├── assets/js/              全局脚本，按固定顺序加载
├── tools/                  一次性改造脚本与生成器（幂等）
├── tools/checks/           自检体系（断言包 + 静态体检 + run_all.rb）
├── docs/                   文档
├── serve.rb                零依赖本地静态服务器
└── 人教版初中数学知识结构.md/.xmind
```

## 核心能力

| 模块 | 说明 |
| --- | --- |
| 外壳 | 固定左栏（悬停展开、状态记忆、`⌘B` 开合），栏目 8 + 4 |
| 章节 | 三栏阅读器，章节树默认展开，中栏换页不刷新 |
| 图谱 | 满屏画布 + 底部工具条（与白板同源），册/层级筛选、搜索定位、悬浮节点面板、按年级默认 |
| 时间轴 | 一屏一根**完整的**可缩放数轴（六级刻度随缩放细分：学段 / 年级 / 册 / 章 / 节 / 知识点）+ 掌握度彩条层（默认不画；六套色彩方案可选 —— 松绿 / 深靛 / 淡彩 / 暖艳 / 素灰 / 无障碍，各走一个基调，套内七档色相分明）+ 悬停报名字（竖线 + 亮点指示那一格）/ 点击弹知识点卡片（可拖、位置记住、卡片里打标记）+ 当前学习 vs 当前观察双节点（观察点只由"点"决定，拖视野不动它）+ 图例条（七档状态 + 两节点 + 四类特殊标记）+ 标记的加 / 改 / 撤（卡片里点一下贴上、再点一次取消，可同时挂几个；"前置未满足"归系统只读）+ 筛选四维（阶段 / 掌握度 / 难度 / 标记，只变淡不动轴）+ 时间段对比卡 + 方阵卡 + 底部缩略条（放大才出现，点拖即定位）；鼠标分工：滚轮缩放 / 右键拖动平移 / 左键点击 |
| 白板 | 无限画布、压感手写、PS 式工具组、题库与题面卡片、跨页带题、回到知识点 |
| 动线 | 首页 练 / 问 / 画 三出口；练习页"去论坛问"；白板"回到知识点"（`graph.html?q=` 点名定位） |
| 论坛 | 3 个专题板，首页/详情/讨论板/我的帖子，数据驱动 |
| 全屏 | 42 页统一在搜索按钮上方；进入全屏后切栏目**不掉全屏**（覆盖区方案） |
